# Procedure PDFs

This folder is served as static assets at `/procedures/`.

Place the following files here so the procedure pages can expose them as
"절차서 PDF 다운로드" buttons:

- `access-procedure.pdf` — 도급업체 안전보건관리 절차서
- `risk-assessment-procedure.pdf` — 위험성평가 절차서

If a file is missing the procedure page will show a fallback notice.
